📦 软件安装

系统要求

  • Windows 10 / Windows 11
  • 无需安装 Python 环境

首次使用

  1. 将收到的 答题助手 文件夹解压到任意位置
  2. 双击 答题助手.exe 启动软件
  3. 首次打开会弹出授权激活窗口

🔑 授权激活

获取授权码

  1. 打开软件 → 弹出授权窗口
  2. 窗口中显示您的机器码（如 521B-248C-1400-6FF2-...）
  3. 点击 "复制" 按钮
  4. 将机器码发给开发者 → 开发者返回一个授权码

激活授权码

  1. 将收到的授权码粘贴到输入框
  2. 点击 "激活授权码" 按钮
  3. 激活成功 → 自动进入主界面
  4. 底部状态栏显示 ✅ 已授权

⚠ 激活一次后，下次打开软件自动验证，无需再次激活

  • 右侧：运行状态（就绪 / 运行中 / 已停止）

🚀 快速开始

方式一：全自动答题（推荐）

  1. 填写目标网址（辅助模式区域）
  2. 填写账号密码（登录配置区域，可选）
  3. 设置循环轮数和题库
  4. 点击 "▶ 全自动答题"
  5. 软件自动完成：打开网页 → 登录 → 选题 → 答题 → 交卷 → 循环

方式二：辅助答题（半自动）

  1. 填写目标网址 → 点击 "打开"
  2. 手动登录
  3. 切换到需要的模式：
  4. 录题模式：手动浏览题目，自动记录答案到题库
  5. 辅助答题模式：自动匹配题库答案并填入
  6. 点击 "开始"

🔄 循环答题说明

设置 说明
轮数 = 0 无限循环，直到手动点击停止
轮数 = 1 只答一轮
轮数 = 5 连续答 5 轮

循环过程： 1. 打开网页 → 自动登录 2. 选择指定题库 → 开始考试 3. 逐题作答（匹配题库） 4. 交卷 → 检查分数 5. 分数≤98.5 → 自动回顾错题并补录 6. 点击"再考一次" → 进入下一轮

🛠 其他功能

考试回顾

  • 手动触发回顾上一轮答题的错题
  • 点击 "考试回顾" 按钮即可

跑题库

  • 遍历整个题库，检查每道题的答案有效性
  • 点击 "跑题库" 按钮

清空题库

  • 删除数据库中的所有题目
  • 点击 "清空题库" 按钮（慎用）

❓ 常见问题

Q：启动后弹出"未授权"怎么办？

将窗口中的机器码复制发给开发者，获取授权码后粘贴激活。

Q：点击全自动答题没反应？

检查是否填写了目标网址，以及是否已激活授权。

Q：怎么停止答题？

点击 "⏹ 停止" 按钮，当前题目答完后会停止。

Q：答完一轮后软件不动了？

检查网络连接是否正常，或点击 "停止" 后重新开始。

Q：选项匹配不准确？

软件会自动收录错题并更新题库，多答几轮准确率会越来越高。
